From zero to clip

Three steps, then it's muscle memory.

01 — INSTALL

Run the installer

Download for your OS and run it. K-Ripper lands in your Ableton User Library, under Max Audio Effect.

02 — DROP

Drop it on a track

Drag K-Ripper from the browser onto any audio track. It rides along like any other device.

03 — RIP

Paste and rip

Copy a link, click RIP. The clip appears in the first empty slot. Click again mid-rip to cancel.

Before you run it

Two things to expect.

An "unverified developer" warning is normal

macOS: after it's blocked, open System Settings → Privacy & Security and click Open Anyway. Windows: on the SmartScreen prompt, click More info → Run anyway. K-Ripper isn't code-signed yet — the warning is about that, not about the app.

Personal use only

K-Ripper is a tool, free for personal use. Rip only what you have the right to download, respect each source's terms, and don't resell or re-upload audio you don't own.

K-Ripper is open source. Built by a producer, for producers. Bundles yt-dlp (Unlicense) and FFmpeg (GPL).
