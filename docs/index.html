Before first run

Two things to expect.

An "unverified developer" warning is normal

macOS: when it's blocked, open System Settings → Privacy & Security and click Open Anyway. Windows: on the SmartScreen prompt, click More info → Run anyway. K-Ripper just isn't code-signed yet — the warning is about that, not the app.

Personal use only

K-Ripper is a tool, free for personal use. Rip only what you have the right to download, respect each source's terms, and don't resell or re-upload audio you don't own.
